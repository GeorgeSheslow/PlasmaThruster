This Repository is a collection of scripts and code used for the Rail-Type Pulsed Plasma Thruster Project for the University of Sydney.

PPT Interface for thruster firing:
- Recommend downloading vscode and using these instructions to understand how to use an interactive Python file: https://code.visualstudio.com/docs/datascience/jupyter-notebooks
- You wil also need to download pyserial, use: https://pypi.org/project/pyserial/
- Open and read PPT_Interface.ipynb situated in PPT_Interface
- Connect to the thruster using the Serial USB converter
- Read file instructions and run cells in order.
